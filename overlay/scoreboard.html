The accurate way: four printed markers. Clicking corners by hand is the largest source of position error in the whole system — three pixels out costs about 5 mm on the cloth. Four printed markers are found to under a pixel, every time, and if you leave them taped down the camera can re-calibrate itself after a knock.

Depth, if you have a Kinect. Depth does not care about light at all — a shadow has no depth and neither does glare, so a ball is simply 51 mm of "nearer than the cloth" under any lighting, including none. It says where the balls are; colour still says which is which.

The depth sensor is 512×424 with its own field of view, so it needs its own four corners — the colour ones do not transfer.

How balls are found in the picture. Colour needs nothing and works on a well-lit table. YOLO uses a model trained on real pool footage and copes better with a tight rack and poor light, at the cost of a large download.

Read this before installing a model. A .pt file is a pickled Python object, and loading one runs code from that file. Installing a model from the internet means running a stranger's program on this machine. Only use models from a source you actually trust, and prefer downloading the file yourself and installing it from a path.

Walks the chain from the lens to a list of balls and puts a number on every link. It changes nothing and starts no game, so it is safe to run at any point — including twice, once per camera, to settle which one to keep on numbers rather than on how it felt.

Rack up first. All the balls on the table, nobody leaning over it, and leave it alone while it reads. The check that matters most is stability: if a ball that is sitting still appears to wander more than a few millimetres, the table never reads as settled and shots never resolve.

Which balls. This picks both the games that are playable and the colour model used to read the cloth — reds and yellows are two well separated hues, a numbered set is seven plus a stripe test.

Where the camera is. A ball's centre sits one radius above the cloth, so the camera sees it pushed outward from the point under the lens. Say where the lens is and that goes away entirely; leave it and a side mount is out by about 26 mm, against a 70 mm pocket.

Ball size. The detector is told how big a ball is and reads each one's colour from a patch that size, so this has to match the set on the table — English balls are 25.4 mm radius, American 28.6. A caliper beats the camera if you have one.
